# ATP006 — Certified Kubernetes Application Developer (CKAD)

Preparation scaffold: one stage per exam domain, connected through `path.yaml`
to a training series repository. New material is planned, and the course
registration in `astrona-content` stays **draft**.

This exam is part of the current Golden Kubestronaut requirements.

| Stage | Domain | Weight | Series |
| --- | --- | --- | --- |
| STG001 | Application Design and Build | 20% | [ATS027](https://github.com/astrona-io/ATS027) |
| STG002 | Application Deployment | 20% | [ATS001](https://github.com/astrona-io/ATS001) |
| STG003 | Application Observability and Maintenance | 15% | [ATS028](https://github.com/astrona-io/ATS028) |
| STG004 | Application Environment, Configuration and Security | 25% | [ATS029](https://github.com/astrona-io/ATS029) |
| STG005 | Services and Networking | 20% | [ATS030](https://github.com/astrona-io/ATS030) |
